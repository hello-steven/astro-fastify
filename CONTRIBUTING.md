# Contributing

Open an issue before a large change so maintainers can discuss the scope.
For a pull request, keep changes focused and add a test for changed runtime
behavior. Run `npm test`, the example build scripts, `npm run test:smoke`,
and `npm run pack:check` before you submit it.

The adapter supports Astro 7 and Node.js 22.12 or later. Changes to supported
versions need a build test in a small Astro application.

Please report security issues privately to the repository maintainers instead
of opening a public issue.
